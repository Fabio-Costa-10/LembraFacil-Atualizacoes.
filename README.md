# Atualizações do LembraFácil

Este repositório público será usado exclusivamente para distribuir versões instaláveis do aplicativo LembraFácil e metadados de atualização.

O código-fonte do aplicativo permanece em repositório privado.

## Estado atual

A distribuição automática ainda está em preparação. Não há APK publicado aqui até que uma versão seja compilada, assinada com chave estável e validada.

## Segurança

- Nunca publique senhas, tokens ou chaves de assinatura.
- Somente ofereça APKs provenientes de builds autorizados e verificados.
- O Android solicita confirmação do usuário antes da instalação de um APK fora da Google Play.
